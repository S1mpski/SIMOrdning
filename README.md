# SIMOrdning

SIMOrdning is a simple bookkeeping application designed primarily for
educational purposes.

The project is mainly built to help my mom at work teaching students
the basics of bookkeeping / accounting 

> [!NOTE]
> This project is primarily built for research, learning, and educational
> purposes. A significant part of the development has been vibe-coded,
> and the application should not be considered a replacement for 
> professional accounting software.

## Features

- Create and manage bookkeeping entries
- Debit and credit validation
- Chart of accounts
- BAS-based account structure
- Income statement
- Balance sheet
- Overview/dashboard with bookkeeping statistics
- Company creation & management
- Light and dark mode

## Tech Stack

The application is built with:

- Next.js
- TypeScript
- React
- Supabase - Database, SQL & Auth
- Vercel - deployment/hosting 
- MUI X Charts 
- Material UI
